# CinePlus

## Descripción
Sitio web de películas y series. Permite registrarse, iniciar sesión y ver el catálogo
(con géneros, duración o temporadas y sinopsis) en la página principal.
Ingresando como admin, además se podrá administrar el catálogo, agregando, modificando o eliminando películas o series. También hay una página que le muestra las tablas de la base de datos.
